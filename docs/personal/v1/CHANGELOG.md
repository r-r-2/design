# Changelog: personal

Versions follow [semver](https://semver.org). The URL carries the major version (`/personal/v1/`), so a site linked to `v1` only ever gets non-breaking changes.

## 1.1.1 — 2026-11-15

Video end card: opened in a browser, the frame now scales to fit the window instead of spilling off screen. `film.js` stops with a clear message when it isn't run from the published folder.

## 1.1.0 — 2026-11-15

Added the video end card: rules under Motion in DESIGN.md, `video/end-card.html` (one-file template set from its URL, with a single avatar blink and an optional button), `video/film.js` to film it to MP4, and the full-size avatar `assets/avatar-full.png`.

## 1.0.0 — 2026-11-03

First release. Tokens, components, DESIGN.md and a review page, drawn from rr2.dev, notes.rr2.dev and resume.rr2.dev.
