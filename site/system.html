## UI
This site uses the {{title}} design system v{{major}}.
- Before any UI work, read {{site}}{{base}}/DESIGN.md and follow it.
- Load {{site}}{{base}}/brand.css and put class="{{prefix}}" on <html>.
- Copy component markup from DESIGN.md exactly. Use only --{{prefix}}-* tokens and {{prefix}}- classes.
- After changing UI, run: curl -sO {{site}}/check.py && python3 check.py site . --system {{id}}
  Fix every error before handing over.
